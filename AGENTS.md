# Конституция ai-smartflow-core

Используй Git и пути относительно корня этого репозитория. Начинай с [среза состояния](docs/status.md) и [инженерного стандарта](docs/ENGINEERING_STANDARD.md).

## Роли

| Роль | Стартовые документы | Ответственность |
| --- | --- | --- |
| `@arch` | [ADR](docs/ARCHITECTURE_DECISION_RECORD.md), [контракты](docs/contracts.md), срез состояния | Утверждает границы, схемы и переходы состояний, декомпозирует задачи и проводит архитектурное ревью. В Фазе 0 работает с документацией и каркасом. |
| `@dev` | [контракты](docs/contracts.md), стандарт, срез состояния | Реализует согласованные контракты, миграции, workflows и автоматические проверки. Поднимает изменение контракта через `@arch`. |
| `@ops` | [эксплуатация](docs/operations.md), срез состояния, `ops/runners/` | Выполняет preflight, smoke, benchmark и восстановление. Дефекты реализации фиксирует в разделе «Найденные проблемы» для `@dev`. Правки исходников ядра и модулей выполняет `@dev`. |
| `@biz` | Срез состояния, [ADR](docs/ARCHITECTURE_DECISION_RECORD.md) | Задаёт критерии эффекта и ручного контроля. Описывает процесс до и после внедрения, связывает выводы с фактическими данными пилота. Архитектурные изменения передаёт `@arch`. |

Явный тег определяет роль. Без тега выбирай её по задаче. Запрос на реализацию относится к `@dev`.

## Обязательная дисциплина

- n8n оркестрирует, FastAPI выполняет вычисления и ведёт журнал состояния, Смарт-процессы Bitrix24 хранят бизнес-состояние и решения человека.
- Границы API и модулей используют Pydantic v2 с `ConfigDict(extra="forbid")`. Денежные расчёты используют `Decimal` и `ROUND_HALF_UP`.
- При завершении работы обнови [срез состояния](docs/status.md) **in-place**, строго **80–130 физических строк** с учётом пустых. Обновляй затронутые разделы, убирай закрытые задачи и дефекты, оставляй до пяти последних вех. Указывай фактические результаты проверок, порты и метрики.
- Для изменений кода запускай pytest, Ruff и Mypy в согласованном окружении. Для изменений workflow выполняй относящийся к ним офлайн smoke. Фиксируй версию и вариант при каждом изменении промпта.
- Единственный источник актуальных архитектурных решений и контрактов — `docs/`.
