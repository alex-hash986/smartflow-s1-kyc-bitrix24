# S2 · AI-Тендер

[Контракты S2](../../docs/contracts.md#контракты-модуля-s2_tender-кейс-s2) задают границы модуля, DTO, параметры профиля и публикацию.

Структура модуля.

```text
modules/s2_tender/
├── README.md
├── module.py
├── contracts.py
├── extractions.py
├── parser.py
├── matcher.py
├── scoring.py
├── publication.py
└── prompts/
    └── extract_quote.yaml
```

| Файл | Ответственность |
| --- | --- |
| `README.md` | Ссылка на нормативные контракты и структура реализации |
| `module.py` | Адаптер `BaseSmartWorker`, проверка подтверждений S1 по публичным интерфейсам ядра, сбор результата и карты |
| `contracts.py` | Строгие DTO, типы, квантование и инварианты |
| `extractions.py` | Резервирование пакета, кэш КП и учёт затрат в SQLite |
| `parser.py` | Чтение источников, извлечение через FAST LLM, нормализация НДС, проверка арифметики и причины ручной проверки |
| `matcher.py` | Детерминированное сопоставление и проверка полноты и количеств |
| `scoring.py` | Допуск по лимиту и бюджету, кворум, ранги и победитель |
| `publication.py` | Подготовка команды из сохранённой оценки и подтверждённого решения |
| `prompts/extract_quote.yaml` | Версия, вариант и шаблон структурированного извлечения КП |
